# Editing rules

- Read the nearest `AGENTS.md` before making edits in a subtree.
- Start from entrypoints, tests, and local docs before reading many files.
- Prefer small, local edits over broad refactors.
- Preserve existing naming, export style, and colocated test patterns.
- Do not hand-edit generated files when a source file exists.
- When public behavior changes, update docs and examples in the same task.
- When route or scenario behavior changes, check mirrored e2e coverage.
